Evidence and security boundaries

Source identity

Preserve capture date, Workbench release and instance environment in a private register. Do not claim DEV-VERIFIED merely because a screenshot exists.

Irreversible output

Black regions are painted into a new PNG raster, not CSS overlays or reversible annotation objects. Verify the export separately; no algorithm guarantees complete redaction.

Approval gate

All historical Workbench screenshot candidates remain HOLD. Publication still requires rights, image-by-image approval, caption review and evidence classification.

Evidence classes: SOURCE-ONLY — this local utility and documented design; MOCK-ONLY — any synthetic examples used to test the tool; DEV-VERIFIED — requires separate instance read-back or witnessed execution; PRODUCTION-VERIFIED — not established by this workflow. Licensing: this static tool requires no ServiceNow licence.
