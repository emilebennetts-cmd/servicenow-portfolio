When the application exists, but the deployment identity does not match

Deployment identity, release gating and evidence provenance across Universal Delivery Workbench and Diagnostic Workbench 2. Reviewed 8 November 2026. Historical findings are not claims of current instance health.

1. The client's pain & history

Consulting accelerators can evolve through personal development instances, legacy scopes and later hosted demonstrations. The UI may look familiar while the technical application identity changes. Installing a package built for one protected scope into another can fail or create a separate application; a matching display name is not sufficient evidence of compatibility.

Portfolio control records a historical demo target with Delivery scope x_eitsp_vdf while the source repository identifies x_1577958_vdf. The same record reports 29 native acceptance cases not run at that checkpoint. This is a deployment gate, not an invitation to force an update.

2. The ServiceNow solution

Identity-first preflight

Record instance, application sys_id, technical scope, version, source commit and update-set or SDK artifact before any deployment. Compare exact identifiers, not display names. Treat scope mismatch as a stop condition requiring a reviewed migration or target-specific package.

Evidence-led release gates

Capture source tests, authorised install/read-back, persona ACL tests, synthetic engagement walkthroughs and acceptance results independently. Do not promote a source-only capability to DEV-verified because a CI workflow passed.

Separate operational ownership

Diagnostic owns writable operational findings; Delivery consumes governed references. Knowledge Intelligence remains a separately deployed companion package. No cross-scope write or installed navigation integration is assumed without tests.

Safe rollback and audit trail

Retain artifact checksum, commit, deployment window, change approval, before/after application identity and rollback decision. Never infer production readiness from a historical DEV demonstration.
