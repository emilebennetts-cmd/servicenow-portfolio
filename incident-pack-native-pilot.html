01 / The client's pain & history

Drafts are easy. Governing reuse is harder.

In a representative greenfield ITSM delivery, requirements, implementation guides, story backlogs and test plans can grow independently. Copying an old pack risks stale scope assumptions, duplicated tasks and a mistaken claim that a drafted test has actually passed.

Disconnected lifecycle

Scope decisions, candidate patterns and build artefacts are stored separately; the consultant must reconcile them by hand.

Weak provenance

A pack version may be revised after attachment. Without a pinned source and a rationale, review and regeneration become ambiguous.

Unsafe automation

Re-running a generator without stable identity can duplicate requirements, stories and test designs.

Premature acceptance

A successful metadata install and a demo user journey do not prove ACL isolation, concurrency safety, client UAT or Production readiness.

03 / Architectural best practices

OOTB-first, version-pinned and fail-closed

Keep the ServiceNow system of record

Native Incident and Change remain authoritative; a custom Delivery Workbench manages its own governed delivery artefacts rather than replacing ITIL 4 process records.

Separate source generations

A dated pilot deployed in a separate application generation does not verify the entire legacy source branch. Require version and scope alignment before comparing results.

Constrain generation

Use stable IDs, explicit source revisions and safe replay; preserve human decisions and mark changed content for re-review.

Make acceptance independent

Require native ACL/negative tests, update preview, ATF, recoverability, performance assurance and approved release evidence for each target.

Preserve the publication boundary

Private evidence, source code, customer metadata and screenshots are not embedded. Illustrative UI remains labelled MOCK-ONLY.

Document entitlements

Public HTML needs no ServiceNow licence. Native custom app/table rights, roles and ACLs must be checked; ITSM/MIM, IntegrationHub, analytics, AI and external providers are contract-dependent.
