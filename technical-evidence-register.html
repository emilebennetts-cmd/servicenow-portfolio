03 / What is still needed for stronger proof

Evidence from existing architecture, as-built, user-guide and runbook materials is retained as internal reference until each item can be checked for provenance and publication permission. No private Drive links or unreviewed screenshots are embedded here.

  1. DEV-VERIFIED: capture a dated authorised test, instance/build identity, expected versus actual result, and reviewed derivative image.
  2. PRODUCTION-VERIFIED: require separate production approval and evidence; do not infer it from a DEV result.
  3. Gallery release: irreversibly redact customer identifiers, strip metadata, record derivative SHA-256 and obtain explicit publication approval before adding images.

04 / Entitlement considerations

Viewing this static portfolio requires no ServiceNow licence. Operating the underlying scoped applications requires authorised instance access and confirmation of custom-app/App Engine rights. ITSM, ITOM, IntegrationHub/spokes, Performance Analytics, AI and external SaaS providers may each introduce separate subscription, role, transaction or connection requirements; verify against the actual tenant agreement before deployment.
