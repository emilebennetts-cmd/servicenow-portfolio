Verification rules
Source-only: a repository artefact or documentation is not a deployment test. DEV-verified: requires dated instance evidence, matching version and observable outcome. Mock: synthetic screens and simulated integrations must be labelled. Production-verified: requires independently supported production evidence and explicit publication authority. Do not infer deployment from a screenshot alone.
Entitlements: this static review page requires no ServiceNow licence. Running scoped applications, ITSM/ITOM/IRM/CSM modules, IntegrationHub spokes, AI or advanced analytics requires the relevant target-instance entitlements and access rights.
