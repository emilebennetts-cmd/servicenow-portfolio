3 · Architectural best practices

OOTB-first and upgrade-safe

Use standard ITSM workflows and supported platform extension points wherever suitable. Keep custom scopes modular; document dictionary, ACL and integration changes before promotion.

Release and data governance

Maintain source-to-build traceability, immutable evidence references, role-based access, approved test data, rollback plans and explicit DEV → TEST → PROD gates. Apply ITIL 4 change enablement controls.

Integration assurance

Test authentication, replay/idempotency, conflict resolution, error queues, inbound authority and secret handling against approved external environments. Mock tests alone do not prove connectivity.

Screenshot publication

Confirm image provenance, product version and rights; remove identities, instance identifiers, customer records and tokens. Publish only reviewed captures. The existing evidence gallery is a candidate register, not an approved public screenshot set.

Licensing and entitlements

The public static portfolio and its browser-only demonstrations do not require a ServiceNow licence. Installation of the underlying scoped applications requires an authorised ServiceNow instance and confirmation of applicable custom-app entitlements. ITSM/ITOM/IRM/CSM/HRSD features depend on the licensed products used; IntegrationHub spokes, AI and advanced analytics may require separate subscriptions. Live Jira/Confluence/Notion access also requires provider credentials and permissions. Confirm terms with the platform owner before deployment.
