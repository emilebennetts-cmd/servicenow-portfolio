03 / Architectural best practices

Evidence integrity before presentation polish.

Public pages are case-study and reference artefacts, not evidence of installed runtime capability. SOURCE-ONLY means implementation or design supported by source. MOCK-ONLY indicates browser-local demonstrations. DEV-REPORTED describes a historical statement needing independent reproduction. DEV-VERIFIED and PRODUCTION-VERIFIED require attributable, dated native execution. Do not infer either from an attractive UI or successful GitHub CI.

Static portfolio browsing requires no ServiceNow licence. Native Workbench installation can require App Engine/custom application and table entitlements, roles/ACLs and product-specific ITSM, ITOM/Discovery, ITAM, SecOps, IntegrationHub, analytics, AI and third-party licensing. Actual entitlements must be verified on the target instance.
